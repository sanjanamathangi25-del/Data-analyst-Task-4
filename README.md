# Data-analyst-Task-4
Task 4: Dashboard Design – Data Analyst Internship

Project Overview

The objective of this task is to design an interactive dashboard for business stakeholders using sales and financial data. The dashboard helps users understand business performance and make better decisions through data visualization.

Tools Used

- Power BI / Tableau
- Microsoft Excel
- Kaggle Dataset

Dataset

A Sales/Financial dataset from Kaggle is used for analyzing business performance, sales, profit, and growth.

Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Sales Growth
- Total Orders
- Profit Margin

Dashboard Features

1. Interactive charts and visualizations.
2. Slicers and filters for data exploration.
3. Time-series analysis to identify sales trends.
4. KPI cards to display important business metrics.
5. Consistent colors and dashboard design.
6. Navigation menu for easy access.

Project Deliverables

- Interactive Dashboard
- PowerPoint (PPT) Summary
- Dataset and Dashboard Screenshots

Learning Outcomes

- Learned how to create interactive dashboards.
- Understood KPI selection and visualization.
- Improved data analysis and interpretation skills.
- Learned how to identify business trends.
- Developed skills to support data-driven business decisions.

Conclusion

This project helped me understand how to transform raw sales data into meaningful visualizations using Power BI/Tableau. The dashboard provides useful business insights and supports better decision-making.
